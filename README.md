## 工作規則

1. 只修改自己負責的頁面；共用的 `css/style.css`、`js/main.js` 由組長修改（或先在群組說一聲）。
2. 開始工作前，先在原始檔控制按「同步變更」。
3. 圖片放在 `images/`，檔名用英文小寫加連字號（例如 `farm-bird-line-01.jpg`），每張 300 KB 以內。
4. 連結與圖片一律使用相對路徑，不要以 `/` 開頭。
5. 新增圖片時，同時把出處寫進 `sources.html`；農場提供的照片寫「照片提供：日晒米屋－鹿光米」。
6. 重要的 Copilot 提示詞記在 `PROMPTS.md`。
7. 完成 Issue 時，在提交訊息最後加上 `closes #編號`。

## 版面怎麼用？（照提案的「滑動閱讀」）

| 想做的效果 | 用法 |
|---|---|
| 一屏一重點、圖文交錯 | `<section class="screen reveal">`；想讓圖片在右邊，加 `flip-side` |
| 知識小卡 | `<div class="kcard"><h3>你知道…嗎？</h3><p>…</p></div>` |
| 下一站按鈕 | `<div class="next-stop"><a href="sun.html">下一站：04 日光溫室曬穀</a></div>` |
| 捲動時淡入 | 任何區塊加 `reveal` |

## 互動元件怎麼改？

| 想改的東西 | 改哪裡 |
|---|---|
| 首頁命題文字 | `js/main.js` 的 `MOTTOS` |
| 翻牌知識卡 | `land.html` 的 `<button class="flip">` |
| 田邊鄰居 | `neighbors.html` 的 `<article class="nb">` |
| 稻穀旅程步驟 | `sun.html` 的 `#journey` 按鈕與 `data-detail` |
| 小測驗題目 | `js/main.js` 的 `QUIZ` |
| 投票選項 | `table.html` 的 `.vote-btn` 與 `js/main.js` 的 `SEED` |
| 營養數值 | `health.html` 長條圖與 `js/main.js` 的 `RICE` |

**投票說明**：票數只存在每個人自己的瀏覽器（起始票數是示範值）。要看全班真實結果，請用 Google 表單＋回應試算表，把表單嵌入碼貼到 `table.html`。
